# Phase 3 — UI Design Contract

> Visual and interaction contract for Phase 3 reader-surface changes to `out/digest-{week_id}.html`. Generated by gsd-ui-researcher; verified by gsd-ui-checker (revision 1).

**Scope:** Plain static HTML only — no Astro, no JS, no client framework (Phase 4 owns dashboard). **Design system source of truth:** inline `_CSS` in `pipeline/render/html.py`. This document formalizes tokens and locks new structure, class names, and reader-surface copy constants.

**Compliance:** LOCKED-01 — `#also-seen`, `.card`, `.card-degraded`, `QUOTA_BODY_COPY`, and `_partition_cards` routing remain untouched except where Phase 3 *adds* sibling structure inside `<main>`.

**Primary focal point:** Weekly-synthesis paragraph when present; otherwise the Briefing Top-N section.

## `<main>` Document Order

Top-to-bottom inside `<main>` (after `<header>`). Order locked per DISPLAY-03 + ROADMAP Phase 3 SC #2.

| # | Element | Condition | Class / tag |

## Copywriting Contract

All strings below are **reader-surface** (D-24): plain English, no enum codes, no CLI paths, no exception class names. Store as module-level constants in `html.py` (mirror `QUOTA_BODY_COPY` pattern).

**Substitution pattern:** Templates use `{n}` for the configured Top-N integer. Renderer substitutes at render time (same helper for briefing header and rollup failure copy).

### Locked copy

| Constant | Copy |
|----------|------|
| `BRIEFING_HEADER_TEMPLATE` | `Briefing — Top {n} this week` |
| `CATEGORY_LABELS` | `edtech`→`Edtech`, `business`→`Business`, `technical`→`Technical`, `design`→`Design` |
| `ALSO_COVERED_PREFIX` | `Also covered by ` |
| `ALSO_COVERED_SEPARATOR` | `, ` (comma + space) |
| `PARTIAL_PUBLISH_COPY` | `Pipeline cost estimate exceeded the weekly budget; this week's digest reflects what completed before the cap.` |
| `WEEKLY_ROLLUP_FAILURE_COPY` | `This week's narrative roll-up couldn't be generated. The Top {n} stories are below.` |
| `QUOTA_BODY_COPY` | `The summary couldn't be generated this week.` |
| `#also-seen` heading | `Also seen this week` |

### Also-covered-by rendering (D-64)

- Insert **after** `.card-tldr` (or after `.card-degraded` on quota cards if TL;DR absent).
- Format: `{ALSO_COVERED_PREFIX}{member_link_1}{SEPARATOR}{member_link_2}…`
- Each member: `<a href="{member_url}" target="_blank" rel="noopener">{display_name}</a>` — use publisher display name, not `[bracketed]` badge form.
- **Hidden** when cluster member count = 1 (canonical only).
- Exclude canonical member from the list; list non-canonical members in stable order (planner: alphabetical by display name).

### Per-category mini-rollup failure (D-58)

- **No reader copy.** Section renders `.category-header` + cards only; omit `.category-mini-rollup` node entirely.

### Empty / edge states (unchanged + extensions)

| Element | Copy |
|---------|------|
| Main feed empty (no healthy cards) | `No items have full summaries this week. See "Also seen this week" below for outbound links.` — **locked** |
| Briefing empty (rank produced 0) | Omit entire `.briefing` section — do not show empty `<ol>` |
| Category empty | Omit entire `.category-section` |
| Primary CTA | N/A — user action is reading; outbound navigation via card title links |
| Destructive confirmation | N/A |

Distinct **container**, not distinct **voice style** — `.category-mini-rollup` uses body tier (16px, `#c8cdd5`), upright, `margin-bottom: 1rem`. Separation comes from placement (above card stack) and section `<h2>`, not italic or enlarged display type.

## Weekly Synthesis Position

**Above** `.briefing` (DISPLAY-03, ROADMAP Phase 3 SC #2). Partial-publish notice remains **first** inside `<main>` when present (operational warning before editorial content).

## Responsive Behavior

| Breakpoint | Behavior |
|------------|----------|
| All viewports | Single column; `max-width: 720px`; `margin: 0 auto`; side padding `1.25rem` |
| Mobile (<720px) | Column fills viewport minus padding; no horizontal scroll; cards stack full-width |
| Briefing numbers | List markers stay in-flow left of cards; no absolute positioning |
| Touch targets | Title links and attribution links inherit card padding — minimum ~44px vertical hit area via card padding (locked card geometry) |
