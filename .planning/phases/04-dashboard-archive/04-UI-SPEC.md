# Phase 4 — UI Design Contract

> Visual and interaction contract for the dark Astro static dashboard + archive. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (Astro components only; no Radix / Base UI) |
| Icon library | Hand-authored inline SVG (no `astro-icon` dependency) |
| Font | `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` — no web font loads |

**Rationale (icon choice):** D-A7a requires a play-icon glyph beside the publisher badge. Hand-authored 16×16 inline SVG in `PlayIcon.astro` avoids an extra npm dependency, ships zero JS, and aligns with the static-first / privacy framing (D-A3a, D-A7b). Lucide path may be traced once into the component; do not install `astro-icon` for Phase 4.

**Stack deviation (locked):** Astro 6.x + Tailwind 4 per STACK.md; no `@astrojs/react`, no shadcn CLI (D-A3a, D-A5a).

---

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gap, video-glyph `margin-left`, also-meta `margin-left` |
| sm | 8px | Card meta row gap, publisher badge inner padding |
| md | 16px | Card inner padding vertical, briefing-item bottom margin, weekly-synthesis bottom margin, main column side padding (mobile) |
| lg | 24px | Card padding horizontal, main column inner padding, category-section top margin |
| xl | 32px | Header top padding (`2rem`), category-section separator spacing |
| 2xl | 48px | Major section breaks between Briefing block and category sections |
| 3xl | 64px | Page-level spacing; footer-aside top padding combined with border |

**Layout width:** Single `720px` max-width column at every viewport (D-A6b). Horizontal padding: `16px` mobile (`1rem`), `20px` tablet+ (`1.25rem` — matches `html.py`).

**Exceptions:** Touch targets ≥ 44px on mobile for all tab links and Archive link (D-A6a). Tab bar wraps to two rows; no horizontal scroll.

## Typography

Four sizes, two weights (card titles use 16px semibold — no separate 18px tier):

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Label / meta | 14px (`0.875rem`) | 400 | 1.5 | Card meta row, video indicator, also-covered-by, partial-publish text, archive excerpt date, pipeline-notice summary, updated timestamp uses 14px at muted color |
| Body | 16px (`1rem`) | 400 | 1.5 | TL;DR, briefing list body, weekly synthesis, mini-rollups, archive excerpt body, card titles (semibold below) |
| Section heading | 22px (`1.375rem`) | 600 | 1.2 | Briefing header, category header, archive row week heading |
| Display | 28px (`1.75rem`) | 650 | 1.2 | Project name H1 in header |

| Special | Size | Weight | Line Height | Usage |
|---------|------|--------|-------------|-------|
| Card title | 16px (`1rem`) | 600 | 1.35 | Story title link — bumped weight instead of larger size (replaces html.py `1.1rem`) |
| Briefing ordinal | 16px (inherits list) | 650 | 1.5 | `<ol>` marker styling — ordinals must feel distinct from body copy (D-A5b) |

**Body line-height:** `1.5` (tighter than html.py `1.6`; ui-brand default).

**Heading line-height:** `1.2`.

**Font:** System stack only — see Design System table.

### CSS variables (`web/src/styles/globals.css`)

Use shadcn default names verbatim (D-A5a). Format: `hsl(var(--background))` in Tailwind theme.

```css
:root {
  color-scheme: dark;
  --background: 216 22% 7%;
  --foreground: 0 0% 90%;
  --card: 216 20% 10%;
  --card-foreground: 0 0% 90%;
  --muted: 216 20% 10%;
  --muted-foreground: 216 13% 65%;
  --border: 216 21% 20%;
  --accent: 213 100% 75%;
  --accent-foreground: 216 22% 7%;
  --destructive: 0 25% 72%;
}
```

**Accent reserved for:** link hover, `:focus-visible` rings (2px outline, 2px offset), active tab indicator, canonical `← Latest week` back-link hover, card title link hover, card `:hover` background lift is **not** accent — hover uses `#1c2230` only.

**Accent NEVER for:** general body text, publisher badge background, category section dividers, tab labels at rest, pipeline-notice band.

**Link colors at rest:** primary text `#e6e6e6`; secondary attribution links `#c8cdd5`. Hover → `#7eb6ff` + underline where applicable (matches html.py).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary navigation action | Tab labels: `Briefing` / `Edtech` / `Business` / `Technical` — capitalized plain English (D-24) |
| Archive row link | `Read this week` (implicit: navigates to `/digest/{week}` Briefing) |
| Back from archive | `← Latest week` → `/` |
| Card title link | Opens source in new tab (`target="_blank" rel="noopener"`) — no separate "Read source" label (DISPLAY-08) |
| Empty state heading (archive) | `No past digests yet` |
| Empty state body (archive) | `The first weekly digest will appear here after the pipeline runs.` |
| Pipeline notes zero-state | **No DOM element** — entire `<details>` omitted when nothing to surface (D-A4a, D-26) |
| In-place degraded card body | `The summary couldn't be generated this week.` (LOCKED-01 / `QUOTA_BODY_COPY` — verbatim) |
| Weekly rollup failure | `This week's narrative roll-up couldn't be generated. The Top {n} stories are below.` |
| Budget halt / partial-publish | `The pipeline reached its weekly cost cap before finishing every summary. This digest reflects what completed before the cap.` |
| Silent-source (3+ empty weeks) | `{publisher} didn't publish for the {N}rd/th week in a row.` — e.g. `Where's Your Ed At didn't publish for the third week in a row.` |
| Fetch failure | `{publisher} couldn't be reached this Sunday morning. The next run will retry.` — e.g. `Ben's Bites couldn't be reached this Sunday morning. The next run will retry.` |
| Pending-local aggregate | `{N} video transcripts will fill in when the digest is refreshed from a different network.` |
| Quota-exhausted aggregate | `{N} summaries hit the weekly LLM budget and weren't generated this run.` |
| Briefing section header | `Briefing — Top {n} this week` (`BRIEFING_HEADER_TEMPLATE`) |
| Also covered by | `Also covered by ` + comma-separated publisher links (`ALSO_COVERED_PREFIX`) |
| Footer aside heading | `Also seen this week` (link-only thin RSS stubs — LOCKED-01) |
| Destructive confirmation | NONE — read-only dashboard |

**Voice:** D-24 plain English, D-50 anti-slop. No CLI syntax, error class names, file paths, or `[video]` text suffix.

## Layout & Routes

Static pre-rendered pages only (D-A3a). Zero client-side routing, zero tab JS.

| Route | Content |
|-------|---------|
| `/` | Latest week Briefing |
| `/{topic}` | Latest week topic tab (`edtech` \| `business` \| `technical`) |
| `/digest/{week}` | Archived week Briefing |
| `/digest/{week}/{topic}` | Archived week topic tab |
| `/archive` | Newest-first week index |

**Header order (mobile stacks vertically — D-A6c):** project name → week range (`Week of MMM D – MMM D, YYYY`) → `Updated {ISO8601}` → Pipeline notes `<details>` (if any) → nav row (tabs + `Archive` link). Archive-week pages add `← Latest week` before or beside nav.

**Briefing tab main column order:** Pipeline notes `<details>` (top of `<main>`) → partial-publish band (if budget halted) → weekly synthesis → rollup-failure notice (if applicable) → Briefing Top N → per-category mini-rollups + ranked cards → footer aside.

**Topic tab main column order:** category mini-rollup → that category's ranked cards. No category badge on cards (tab context conveys category).

**Archive index row:** `Week of MMM D – MMM D, YYYY` (22px heading) + first sentence of weekly synthesis (fallback: top-1 story title) at 16px + link to `/digest/{week}`.

**Canonical metadata:** Latest-week pages emit `<link rel="canonical" href="/digest/{week}">` or `/digest/{week}/{topic}`. No user-facing copy.

## Interaction & Accessibility

| Behavior | Contract |
|----------|----------|
| Tabs | Static `<a href="...">` — full page navigation; works with JS disabled |
| Pipeline notes | Native `<details>` / `<summary>` — zero JS |
| Card hover | Background `#1c2230`; no transition when `prefers-reduced-motion: reduce` |
| Focus rings | `:focus-visible` — 2px solid `#7eb6ff`, 2px offset on tabs, card links, source links, archive links, back-link, `<summary>` |
| Motion | No delight animations; hover only where noted |
| Video hint | Play glyph inline SVG next to publisher badge when `source_type === 'youtube'` (DISPLAY-06, D-A7a) |
| External links | `target="_blank" rel="noopener noreferrer"` (DISPLAY-08) |
| Touch targets | Tab + Archive links min 44×44px hit area on mobile |

## Data → UI Mapping (LOCKED-01)

Python pre-partitions JSON before Astro (D-A1). Astro never routes cards.

| JSON list | Surface |
|-----------|---------|
| `briefing_top_n[]` | Numbered Briefing list |
| `category_sections.{topic}.cards[]` | Topic tab + Briefing category blocks |
| `main_feed[]` | In-place cards (ok + degraded transient statuses) |
| `footer_aside[]` | Footer aside — `summary_status='thin'` only |
| `pipeline_notes` | `<details>` aggregate + expanded breakdown |
| `failure_notice` | Rollup failure / partial-publish bands |

Degraded body string comes from JSON field populated with locked `QUOTA_BODY_COPY`.
