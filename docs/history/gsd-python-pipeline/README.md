# Retired plan: the Python pipeline (May 2026)

These are the GSD planning files for the first version of AI Digest: a Python pipeline with SQLite, Gemini, GitHub Actions cron, Backblaze B2, and a home worker. That pipeline was replaced in October 2026 (DAS-27) by the current Astro site, where each week arrives as a JSON file in `content/digests/`.

Nothing here describes how the site works today. It is kept as history only.

- The current plan lives in Linear, in the AI Digest project.
- The rules the weekly run follows live in `config/`.
- The locked directives still apply and stay at `.planning/LOCKED-DIRECTIVES.md`.

The v2 ideas in `REQUIREMENTS.md` (search, shareable links, community pulse, podcasts) remain a useful idea list. The pre-public-release privacy sweep in `PROJECT.md` still applies before the repo is made public, and covers this folder too.
